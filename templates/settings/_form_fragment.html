{# A screen's `page` block on its own, for an htmx swap. #} {# #} {# The mirror of `_list_fragment.html`, and it exists for the same reason. #} {# A template extends whichever base its view asks for: on a normal #} {# request that is `shell.html` and the whole page renders; on an #} {# HX-Request it is this file, which emits the `page` block and nothing #} {# else — no rail, no sidebar, no top bar, no second . #} {# #} {# Named for the write screens it was built for, and used by every #} {# template whose own top-level block is `page` — which includes the #} {# detail screens, because those extend their base directly rather than #} {# through `settings/base_list.html`. Pairing one of those with #} {# `_list_fragment.html` produces a 200 with an empty body: that file #} {# declares only `results`, and Django silently drops a child block the #} {# parent does not have. Which fragment a screen wants is decided by the #} {# block it defines, never by whether the screen is a list or a form. #} {# #} {# Without it a panel swap receives a whole document. That renders well #} {# enough to pass a glance and is wrong in every accessibility tree, and #} {# the defect is invisible until somebody opens the panel rather than the #} {# page. #} {% block page %}{% endblock %}
